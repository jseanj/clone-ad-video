# Platform Specs & Message-Match 工作表

整理自 TikTok、Instagram Reels、Facebook Feed、YouTube Shorts 等主流商业投放渠道的官方像素规范与 UI 安全区。

---

## 一、 比例与投放版位映射

| 比例 | 分辨率 | 原生投放版位 | 安全区建议 |
| :--- | :--- | :--- | :--- |
| **9:16** | 1080×1920 | TikTok In-Feed, Instagram/Facebook Reels, Stories, Shorts | 顶部避开 270px (14%)，底部避开 480~600px (25~32% 存放文案/头像/CTA 栏)，两侧避让 65px |
| **4:5** | 1080×1350 | Meta/Facebook Feed (信息流最佳转化率版位) | 顶部避开 5%，底部避开 10%，两侧居中 90% |
| **1:1** | 1080×1080 | Instagram Feed, Twitter/X, 通用自动版位 | 正中心 90% 绝对安全区 |
| **16:9** | 1920×1080 | YouTube In-stream, 网页落地页嵌入 | 中心 90% 绝对安全区 |

> [!IMPORTANT]
> **中心 1:1 保活原则**：
> 永远将关键文字标语、产品交互主体与 CTA 按钮布局在画面**正中心 1:1 方块**内。这样无论如何重裁剪，主体永不脱出画面。

---

## 二、 平台 UI 交互覆盖避让指南 (Keep-Clear Safe Zones)

以 **9:16 (1080×1920)** 竖屏信息流为例：
```text
+---------------------------------------------------+
|               Top 270px (~14%)                   |  <- 顶部状态栏、返回箭头、搜索栏 (保持净空)
|               (KEEP CLEAR)                        |
+---------------------------------------------------+
|                                                   |
|                                                   |
|             CENTER SAFE ZONE (1080x1080)          |
|                                                   |
|           • Hook 标题与痛点大字                      |
|           • 核心产品演示 / 真实背书卡片               |
|           • 关键动效与视觉焦点                      |
|                                                   |
|                                                   |
+---------------------------------------------------+
|               Bottom 540px (~28%)                 |  <- 账号名、视频描述文字、展开按钮、音乐标签
|               (KEEP CLEAR OF CTA & TEXT)          |     以及右侧点赞/评论/分享图标列
+---------------------------------------------------+
```
